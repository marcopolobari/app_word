Ambiente LaTeX — scrittura rapida delle equazioni
✎ Modifica di una formula già inserita nel documento: verrà sostituita.
Pronto — scrivi le formule: si trasformano mentre digiti.

Strutture (pulsanti in alto)

  • a/b frazione: numero sopra, denominatore sotto
  • √ radice quadrata  ⁿ√ radice n-esima
  • x₂ pedice  x² esponente
  • v⃗ vettore: scrivi la lettera, poi premi v⃗ Vettore (barra sopra l'editor) — il cursore resta dopo il vettore: _ pedice, ^ esponente, oppure prosegui
  • lim limite  { } sistema di equazioni
  • ∑ formula in codice LaTeX
  • Ω palette dei 63 simboli

Sintassi rapida

  • f(1/2) → frazione 1/2
  • radq(x+1) → radice quadrata
  • radn(3;x) → radice n-esima (indice;radicando)
  • sist(x=1;y=2) → sistema
  • lim(f(x);x;oo) → limite (espr;variabile;∞)
  • _(tot) → pedice   ^(2) → esponente
  • F_att → pedice di più lettere (Fatt)
  • vec(F) → vettore   F+v → \vec{F}
  • Pulsante v⃗: prende la lettera sotto il cursore (o la selezione)
  • \aa → α   \beta → β   \inf → ∞
  • \frac{1}{2} → LaTeX completo

Tastiera

  • Tab / Shift+Tab slot successivo / precedente
  • / nel numeratore → salta al denominatore
  • ← → scorri l'equazione (e le sue parti)
  • ↑ ↓ numeratore ↔ denominatore, righe del sistema
  • ↑ dal pedice/esponente → torna alla base
  • _ / ^ nel pedice o nell'esponente → completa la base
  • _ / ^ dopo una lettera → apre ( ) col cursore dentro
  • Invio / Esc chiude la struttura (diventa formula)
  • Canc a inizio slot → slot precedente / elimina struttura
  • Ctrl+→/← parola per parola

Modificare le formule

  • Doppio click su una formula del documento → si riapre qui, editabile
  • Frecce ← → su una formula già scritta → la riapre per la modifica
  • Inserisci nel documento sostituisce la formula originale
  • Annulla modifica (barra gialla) lascia il documento invariato
  • Simboli della palette convertiti in LaTeX (α → \alpha, ∑ → \sum)
  • Vettore, pedice ed esponente si possono combinare: F+v+_att+^2
  • Export DOCX: le formule diventano equation native di Word

Il riquadro bianco è l'area di scrittura: il pannello si ridimensiona con la finestra.
